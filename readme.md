# Project Super Stellar 언어 확장 패키지

[Project Super Stellar](https://www.roblox.com/games/115672909479646/Superstellar-Next-Generation)

이 패키지는 Project Super Stellar의 언어 확장 패키지입니다.
이 폴더에는 게임의 언어 설정 파일이 있습니다.

현재 지원되는 언어:
- ko-KR (한국어)

# Project Super Stellar Language Extension Package

[Project Super Stellar](https://www.roblox.com/games/115672909479646/Superstellar-Next-Generation)

This folder contains language configuration files for the game.
Each language has its own folder.
Folder names follow the ISO 639-1 standard.
Each language folder contains the configuration file for that language.

Currently supported languages:
- ko-KR (Korean)
- en-US (English) [local]
- fr-FR (French) [local]
